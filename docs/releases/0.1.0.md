## New Feature(s)
- First release of GPU Monitor, a desktop application for Windows (amd64) and macOS (arm64) that monitors the GPUs of remote Linux hosts over SSH.
- Show utilization, memory, temperature, power draw, clocks, and per-process usage in real time, sampled every 200 ms.
- Support NVIDIA, AMD, and Intel GPUs.
- Monitor multiple hosts from one window, with automatic reconnection after an unexpected disconnection.
- Require no root privileges, no remote installation, and no remote daemon, and never store passwords.
- Record every connection and review it on the history screen.
- Sort and filter the process list.
- Choose the appearance, the interface language (English or Traditional Chinese), the memory size unit, and the charted metrics in Settings.
- Install with the .msi package on Windows or the .pkg package on macOS.
